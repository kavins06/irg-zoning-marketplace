# Zoning Report

Use the site-zoning skill in ChatGPT or Claude with your separately connected **Zoning MCP**. Ask “Prepare an IRG zoning report for [address] using Zoning MCP.”

The plugin contains the report instructions only. Edit the [site-zoning skill](plugins/zoning-report/skills/site-zoning/SKILL.md) to update the template for both clients.
